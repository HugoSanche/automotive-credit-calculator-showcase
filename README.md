🚗 Automotive Credit Calculator

Enterprise-level web application developed with Spring Boot for automotive financing and leasing quotation management.

Overview

The Automotive Credit Calculator is a full-stack web application that automates the quotation process for automotive financing products.

The platform allows financial institutions to calculate loan payments, leasing proposals, generate professional PDF quotations, and manage business rules through a secure administration portal.

# Business Features

✔ Automotive Loan Calculator

✔ Leasing Calculator

✔ Balloon Payment

✔ Residual Value

✔ Amortization Schedule

✔ Interest Rate Management

✔ Business Rules Administration

✔ Vehicle Years Configuration

✔ Payment Day Configuration

✔ PDF Report Generation

✔ Secure Authentication
